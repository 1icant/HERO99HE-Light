# HERO 99HE Light Studio v0.1.12

面向狼蛛 HERO 99HE 的独立实时 RGB 灯光控制台。不是 AULA_LED 的补丁，也不是狼蛛官方软件。原来的程序和端口 8720 没有修改。

**状态：实验版。按键颜色、后台保活和色卡已获用户确认。本版新增联动与鲜亮增强，仍需实机复测。Esc 未响应仍未解决。**

## v0.1.12 图示键位、6 种联动与鲜亮增强

- 顶排 Fn 显示改为 PrtSc / PrintScreen，空格右侧改为 Fn（无标准浏览器键码）；修正 E 键间距，保留原硬件地址与项目布局版本，旧配色不换位。
- 新增主色聚焦、横向追光、同色呼吸、互补映色、左右交融、击键闪耀。均使用整条 RGB，不新增逐灯或矩阵协议。键盘变化时跟随完整帧；静态按键下动态联动可用空闲预算，不锁在 250ms 保活上。
- 鲜亮增强 100–200% 同比提亮 RGB，以峰值通道限制增益，保持色相/黑色；与原生 1–5 档和按键亮度分开。旧配置缺失 gain 时为 1（100%）。满值白光不能再亮，未验证与官方驱动最大亮度一致。
- 页面版本 v0.1.12、桌面 v0.2.2。32 按键效果、30 色卡、3+1 联动包预算及 80 包/秒限速保留。GitHub 首页文档见仓库根目录 README.md。

## v0.1.10 快速灯带、独立亮度与直接操作（历史，组合输出策略已更新）

- 移除“已关闭其他灯光软件，允许按键输出”和“允许控制灯带；设备可能记忆设置”两项勾选。连接后直接点“开始输出”或“应用灯带”。加载、连接、预览、导入和暂存灯带参数都不会自动开始；停止、断开、传输错误仍结束发送。设备型号/能力检查保留。
- 取消 v0.1.9 为按键预留 90% 带宽的策略：它令复杂画面的灯带实际只有约 6Hz。本版以 25ms / 40Hz 为灯带最快目标，满载时完整按键帧后及时补灯带，共用原 80 包/秒预算，不提高总包率或并发写入。四包按键加一包灯带上限约为两者各 16Hz；这是换取更快灯带的明确带宽取舍，不保证所有模式 40Hz。
- 分开按键帧率计时与共享包预算。低按键 FPS 不再让灯带等键盘帧率计时器；灯带能力读取和单次设置也不再多等按键帧率计时。包间隔仍至少 5ms，排空仍 8ms，无流式 ACK 等待、积压补发或错误重试。
- 灯带不再乘按键亮度。纯色、呼吸、配色、余辉等使用自身完整 RGB；跟随模式取未乘按键亮度、经过稳帧处理的颜色构成，保留画笔与动画颜色，即使按键亮度为零也能亮。灯带硬件亮度仍是原厂 0–4（网页 1–5 档）；5 档最亮，没有未知的增亮指令。旧配置的档位保留，需要更亮请设 5 档后应用。
- 模拟对比：四包空间光波 5 秒，灯带从 v0.1.9 的 31 次提高到 80 次，键盘从 93 帧变为 81 帧；两包 20FPS 动画仍 101 帧，灯带 150 次。5FPS 按键目标时，3 秒 16 帧按键、98 次灯带。独立动态灯带约 40Hz；均不是实机性能保证。
- 32 种效果与原 30 组色卡不变。高频原生设置可能被设备记忆，存储实现和长期影响尚未验证；停止不恢复原厂灯效。

更新：先停止并断开旧输出，在 `http://127.0.0.1:8731/` 按 Ctrl+F5，确认 v0.1.10 后重新连接。灯带亮度设 5 档，选模式后直接点“应用灯带”；之后修改应用无需刷新。异常请停止并导出诊断。旧压缩包保留。

## v0.1.9 自适应灯带刷新与 32 种灯效（历史，预留策略及亮度关系已由 v0.1.10 替代）

- 移除 v0.1.8 将整个键盘循环锁在灯带 250ms 周期上的代码。250ms 不是已知硬件要求；它只继续用于未变化按键画面的原有保活。
- 灯带目标周期最低 50ms（最高目标 20Hz），按当前按键帧包数与帧率预留键盘带宽；复杂四包动画通常以约 125ms 为灯带目标周期，按完整帧边界调度后可能更慢。未变化的键盘画面释放未用动画带宽。不是所有模式都保证 20Hz。
- 到期的灯带报文直接接在完整键盘帧尾部，同一次发送事务计入总包数，省去额外的帧率等待；绝不插入键盘分包中间。继续串行、最多 4 个按键包/帧、至少 5ms 包间隔、8ms 排空、共用持续 80 包/秒预算；不降低原有颜色精度来换速度、不新增原厂模式或逐灯地址。
- 灯带颜色相同但按键输出过时，到期仍补一次兼容刷新；独立静态灯带仍去重。原生回执不阻塞循环；USB 失败停止双方且不自动重试。
- 新增霓虹渐流、纵向彩虹、斜向流光、星云旋涡、等离子、数字雨、双向彗星、中心扩散、光幕开合、菱形脉冲、丝带流光、萤火游弋、行星环绕、暮色潮汐、按键烟花、十字光痕，共 32 种，可按流动/氛围/按键互动筛选。原有 30 组配色色卡不改。
- 模拟时钟：四包空间光波 5 秒，单键盘 101 帧、加灯带 93 帧，灯带 31 次，最大帧起始间隔 62.5ms；两包动画 101 帧、灯带 100 次。软件模拟不代表实机帧率或视觉生效保证。

更新：先停止并断开旧输出，在 `http://127.0.0.1:8731/` 按 Ctrl+F5，确认 v0.1.9 后重新连接。开始按键输出，再选灯带模式、允许灯带控制并点“应用灯带”；之后修改应用无需再次刷新。若异常请停止并导出诊断。

灯带仍是整条同步颜色，不是逐灯跑马。停止不会恢复原厂灯效；原生设置可能被设备记忆，其长期存储影响未经验证。旧版压缩包全部保留供回退。

## v0.1.8 灯带应用、兼容联动与简洁界面（历史，250ms 组合限速已由 v0.1.9 替代）

已确认的软件原因：旧界面用 `running` 禁用灯带应用和输入；联动许可只在启动时锁定；流式灯带更新阻塞等待原生回执，350ms 未收到就停止全部输出。另针对用户反馈的按键输出后灯带失效，加入“完整键盘帧 → 灯带设置”的兼容组合顺序；此固件覆盖机制尚未通过本代理的硬件实验确认。

- 无需刷新：按键输出中也能编辑灯带并点“应用灯带”。应用会等待停止/排空，必要时读取本次能力，再以新灯带配置启动，保留原本是否输出按键。停止、断开、撤销许可或导入会取消尚未完成的应用，避免后台意外重启。
- 独立应用灯带不需要按键输出许可，也不写按键颜色。支持先灯带再按键、先按键再灯带、重复修改应用。能力只在用户明确允许灯带并点击应用/开始时按需读取，不因页面加载、连接或预览自动查询。
- 联动时每一个完整按键帧最后都发送灯带常量颜色，即使它没有变色；避免旧版去重后不再覆盖回来。兼容组合更新采用最多约 4 次/秒的低频节奏，排空会使实际更低，**同时降低联动时的键盘实际动画帧率**。仅按键输出不受此兼容限速影响。
- 流式输出以 USB `sendReport` 完成为发送依据，不等待每次原生 ACK；缺 ACK 不阻塞或判作“不支持”。仅被动统计格式/校验正确的 `04/06` 回执，不把发送成功或 ACK 当作视觉成功。USB 发送失败仍停止全部输出、不重试失败报文。独立静态灯带去重，组合帧后的重复写入是兼容刷新，不是错误重试。
- 配色从 10 组扩展为 30 组，支持中文搜索。点预设时若原来为固定彩虹、红色热力或动画模式，会切为配色渐变，让配色可直接看到；退出动画帧编辑，但不删除已存动画或画笔颜色。其他模式保留。
- 页面重构为键盘预览、灯效卡片、配色色卡和独立的键盘/灯带调节卡。移除主界面的协议说明、实时计数和日志；高级设置折叠，数据只在本地诊断中导出。保留必要的许可、记忆设置风险和简短状态。

复测：

1. 停止并断开旧输出，在 `http://127.0.0.1:8731/` 按 Ctrl+F5，确认 v0.1.8，重新连接。
2. 先只允许按键输出并开始，选择喜欢的配色。
3. 选择灯带“联动 · 跟随键盘颜色”，勾选灯带许可，点击“应用灯带”。程序自行处理暂停/继续，不需要刷新或手动先检查能力。
4. 再改灯带模式/亮度并应用，或切换配色，观察按键与顶部灯带是否都持续响应。如果仍失效，停止并导出诊断；报告区分已提交数量与观察到的回执数量。

灯带依然仅为整条同步颜色，不是逐灯跑马。按键触发依然只接收页面内事件。停止不自动恢复，设备可能记忆原生设置；尚未确认固件存储实现或长期影响。工具不发 save/reset/刷机命令，原有 v0.1.7 压缩包保留供回退。

- 联动每次等待对应回执，350ms 未收到合法回执或出现错误就停止全部输出、不自动重试；单次纯色测试仍为 2 秒超时。诊断包含联动模式、更新次数与失败报文。

## v0.1.5 短响应处理与失败诊断（历史；解析规则由 v0.1.6 修正）

以下描述当时的行为。此前把长度为 0 的非空固定数据区当成填充区，是查询专用解析路径的遗漏，不再适用于 v0.1.6。

用户的 v0.1.4 诊断显示，查询收到通过接口/报文头/校验和检查的匹配响应，但被“数据长度至少 21 字节”的假设拒绝；旧版错误报告只保留错误文本，未保存响应，因此无法恢复其真实长度和内容。这里不能认定设备不支持灯带，也不能认定它一定是 ACK。

- 允许通过完整报文校验的 0–56 字节有效数据，缺失能力字段使用 `null` /“未知”，不读取填充区，不把未返回字段当作“不支持”。超过 56 仍拒绝，报错包含具体长度。
- 短响应后继续监听至原有两秒期限，若随后收到完整数据则使用完整数据；不另发查询、不自动试其他命令。若只有短响应则返回部分信息并明确标注，不启用灯带输出。
- 每次查询最多保留前 8 个匹配响应及总数量、声明长度、实际报文长度、原始字节；失败信息跨 Worker 传回并写入诊断。其他输入报告仍忽略，不记录按键内容。

## 启动

1. 将整个文件夹放在一起，双击 `启动控制台.cmd`，不需要安装 Python、Node 或第三方库。
2. 浏览器打开 `http://127.0.0.1:8731/`。如未自动打开，请手动用 Windows 的 Chrome / Edge 访问。
3. 页面默认仅预览，不请求后台设备权限，不自动连接，也不发送灯光。
4. 使用 USB 有线连接键盘，关闭 AULA HUB、AULA_LED 等可能占用 HID 通道的程序。
5. 点击“连接键盘”，由你在浏览器设备选择器中选择 HERO 99 HE / HERO 99。连接后程序校验接口，但不发送报文；点击能力查询、应用灯带或开始输出才发送对应报文。
6. 直接点击“开始输出”。首次建议使用 20 FPS、较低按键亮度的纯色效果，确认正常后再尝试动态效果；顶部灯带的亮度单独调节，5 档最亮，需点击“应用灯带”。请勿同时运行其他灯光软件。

服务只监听本机回环地址，不对局域网开放。启动脚本的 ExecutionPolicy Bypass 仅作用于该 PowerShell 进程，不修改系统执行策略。若组织策略或安全软件阻止启动，请遵循组织要求，不要降低系统安全设置。

服务窗口需保持运行，Ctrl+C 可关闭。窗口关闭后已载入页面仍可能继续发 WebHID 灯光；要停止硬件输出请点击页面“停止输出”或关闭页面。

若 8731 端口占用，在当前文件夹的 PowerShell 运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Serve.ps1 -Port 8732
```

不要覆盖原项目文件，也不需要删除原项目。

## 功能

- 按图校正的 101 位置可视化预览；32 种键盘模式、30 组可搜索配色和 7 种整条灯带效果/联动，顶部带颜色预览。
- 逐键画笔：左键绘制、按住拖动连涂、右键擦除。非动画模式的逐键颜色覆盖动态灯效。
- 亮度、速度、背景色、5–40 FPS 输出上限。相同画面降为约每 250ms 保活，纯色时实际更新率会降低，这是正常行为。
- 动画编辑器：捕获当前未乘亮度的画面、点击帧编辑、循环预览、25–5000 毫秒帧时长，最多 120 帧。
- 配置仅保存在当前浏览器的本机存储，支持 JSON 导入导出；导入成功会停止硬件输出。
- 本地诊断报告，不上传数据，不记录按键内容或设备序列号。

按键响应只处理本页面获得焦点时收到的浏览器按键事件，也可点击虚拟键帽触发。**不是系统级按键监听**，不能在游戏、其他窗口或后台持续捕获按键。Fn 通常不向浏览器发送事件；网页也无法可靠接收所有系统快捷键。

## 硬件边界与恢复

- 只接受 VID `372E` / PID `103E`、产品名 `HERO 99 HE` 或 `HERO 99`（可带 AULA 前缀）、厂商 Usage Page `FF60` / Usage `61`，且 Output Report 9 为 63 字节的设备。
- 同一 VID/PID 被多款狼蛛设备共用，不能凭这个 ID 判定型号。名字、接口或报告长度不符时一律拒绝发送，不允许“强制兼容”。未选择型号的通用 HID 名称也会拒绝；可反馈诊断与原厂页面设备信息继续适配。
- 实现已观察到的实时 RGB 报文、明确点击的一次只读灯光能力查询，以及通过开始/应用按钮触发的原厂氛围灯常量颜色更新；不发送刷机、恢复出厂、改键、宏、RT、磁轴校准或保存配置命令。
- **停止发送不等于恢复原厂灯效。** 暂时没有实现未经验证的恢复命令；键盘可能保留最后一帧。必要时关闭此页面并重新插拔键盘，再用原厂驱动或说明书中的灯效快捷键恢复。
- 不提供断电保存功能。固件是否自行记忆最后画面尚未实测。
- 遇到异常立即停止并断开；请勿与其他驱动同时控制。不同固件和浏览器后台节流可能导致不同表现。
- 若键位不对应，不要反复试发不同协议；请提供键盘固件版本及原厂布局截图，再核实映射。
