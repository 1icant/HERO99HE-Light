# HERO 99HE Light Studio Web v0.1.26

本地灯光工作台，支持 HERO 99HE 的实时键盘灯效、独立灯带和 Logo。与原来的 AULA_LED 程序及 8720 端口互不影响。

双击 `启动控制台.cmd`，用 Windows Chrome / Edge 打开本地页面。连接并选择 HERO 99HE 的灯光接口后，分别使用「开始输出」「应用灯带」「应用 Logo」。网页的互动按键需要页面焦点，桌面版可使用后台输入。

- 键盘：56 种灯效、30 组内置配色、101 键预览、逐键画笔和 120 帧时间线。支持流动、氛围、互动分类。
- 我的配色：为当前主色、底色及完整渐变配色命名，最多本地保存 60 组，可反复套用。项目 JSON 只导出当前配置，不包含配色库。
- 灯带：关闭、纯色、柔和呼吸、自动取色、原厂彩色霓虹和跑马。自动取色在应用时从当前键盘画面取一次主色，之后保持不变。呼吸和原厂彩色效果由固件播放，不恢复实时联动。
- Logo：单独设置。不接管不会关闭已有灯光；需要关闭时，选择纯色并把亮度设为 0 后应用。
- 配置：本地保存，支持 JSON 导入导出。旧灯带联动设置迁移为关闭，保留颜色和亮度。没有测试面板或诊断上传。

连接、预览、导入不写灯。停止不恢复原厂效果。设备校验包括型号、VID/PID、厂商接口和 Report 9 长度；不发送刷机、改键、重置或保存命令。

运行 `node --test tests/*.test.cjs` 验证软件。协议记录见 [PROTOCOL.md](PROTOCOL.md)，其中旧版本实验不属于当前界面。
