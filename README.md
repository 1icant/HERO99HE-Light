# HERO 99HE Light Studio

面向狼蛛 HERO 99HE 的本地 RGB 灯光工作台。独立工具，不是狼蛛官方驱动，也不是 AULA_LED 的补丁；不包含原厂驱动或远程加载的官方脚本。

当前版本：桌面版 **v0.3.3** · 网页核心 **v0.1.26**。详见 [更新内容](RELEASE-v0.3.3.md)。

- 键盘：56 种灯效、30 组内置配色、最多 60 组自定义配色、101 键预览、逐键画笔和最多 120 帧的动画工作台。
- 顶部灯带：关闭、纯色常亮、柔和呼吸、自动取色、原厂彩色霓虹和彩色跑马。点「应用灯带」时只发送一次；自动取色不会跟随之后的键盘帧。
- Logo：单独应用，可选不接管、纯色、主色直连、自动取色、击键闪亮。
- 桌面版：收进系统托盘后继续运行已启动的软件灯效。可选后台按键响应，默认关闭。
- 已移除 Esc 专项、接口测试面板和灯带的键盘联动。保留正常键位布局和现有项目数据；旧联动模式导入时转为关闭，需手动应用才会写硬件。

## 运行

1. 在右下角托盘右键旧版图标，选「退出程序」。关闭窗口只会隐藏，旧版留在后台会让新 EXE 唤起旧窗口。应用灯效前也请关闭其他灯光驱动。
2. 从 [GitHub Release](https://github.com/1icant/HERO99HE-Light/releases/tag/v0.3.3) 下载 `HERO99HE-Light-Studio-0.3.3-win-x64.zip` 并完整解压到新目录，运行其中的 `HERO99HE Light Studio.exe`。保留旁边的 DLL 和 `resources` 文件夹；确认左上角显示「桌面版 v0.3.3 · Web v0.1.26」。
3. 连接键盘。按键点击「开始输出」，顶部灯带和 Logo 各点自己的「应用」。只连接、预览或导入不会发送灯效。
4. 关闭窗口会收进托盘；右键托盘可停止软件输出或退出。停止不恢复原厂灯效，也不会关掉灯带上由固件自行播放的效果。

详见 [桌面版说明](HERO99HE-Desktop/README.md) 和 [网页版说明](HERO99HE-Light/README.md)。软件未签名，不需要管理员权限，不建议关闭系统安全防护。

Web 版可双击 `HERO99HE-Light/启动控制台.cmd`，在 Chrome / Edge 打开 [http://127.0.0.1:8731/](http://127.0.0.1:8731/)。如需关窗后继续输出，请使用桌面版。

## 配置与开发

配置仅在本机保存，支持 JSON 导入导出。浏览器与桌面版各有自己的本地配置，可以通过导出和导入迁移当前项目。「我的配色」是本地配色库，不包含在项目导出文件中。

- `HERO99HE-Light/`：共享界面、键位、灯效和 WebHID Worker。
- `HERO99HE-Desktop/`：Electron 托盘、权限策略、后台输入和打包工具。

`node --test HERO99HE-Light/tests/*.test.cjs HERO99HE-Desktop/tests/*.test.cjs` 运行软件回归，不连接真实硬件。
