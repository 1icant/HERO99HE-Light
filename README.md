# HERO 99HE Light Studio

面向狼蛛 **HERO 99HE** 的本地 RGB 灯光工作台，提供逐键灯效、顶部灯带联动和 Windows 托盘后台运行。

本项目为独立实验工具，**不是狼蛛官方驱动，也不是 AULA_LED 的补丁**。不包含原厂驱动包或远程加载的官方脚本。

当前版本：桌面端 **v0.2.2** · Web 核心 **v0.1.12**。

## 功能

- **32 种键盘灯效**：彩虹、呼吸、流星、极光、数字雨、等离子、按键余辉等，支持分类筛选。
- **30 组颜色预设**：支持主色、底色、配色、速度和亮度调整。
- **101 个物理位置预览**：独立导航列、数字区、顶排 PrtSc 与空格右侧 Fn，支持逐键涂色。
- **动画工作台**：捕获、编辑和循环播放，最多 120 帧，支持 JSON 导入/导出。
- **顶部灯带独立控制**：独立纯色、柔和呼吸、全彩循环、配色流转、柔光脉冲。
- **8 种联动方式**：原有颜色跟随、按键余辉，加上本版新增的 6 种联动。
- **独立灯带亮度与鲜亮增强**：硬件 1–5 档，软件 RGB 增强 100–200%，不受按键亮度影响。
- **Windows 托盘后台**：关闭窗口后继续输出，托盘菜单可重新打开、停止或退出。
- **本地配置与诊断**：配置保存在本机；诊断文件由用户主动导出，不自动上传。

## 新增灯带联动

| 模式 | 表现 |
| --- | --- |
| 主色聚焦 | 从亮键中提取占优色，减少大量暗键把灯带颜色平均压暗的现象 |
| 横向追光 | 沿键盘左右往返采样，整条灯带显示当前采样区域的颜色 |
| 同色呼吸 | 跟随键盘平均色，并叠加柔和明暗变化 |
| 互补映色 | 根据键盘占优色生成互补色，保留色彩明暗范围 |
| 左右交融 | 在键盘左、右区域的平均颜色之间平滑交融 |
| 击键闪耀 | 以键盘画面为底色，收到页面内按键事件时提亮，随后衰减 |

这里的“灯箱/灯带”指当前已验证接口控制的**整条氛围灯**。上述效果均通过整条 RGB 更新实现，**不是逐灯珠寻址、矩阵屏幕或真正的分区显示**。横向采样发生在键盘画面中，灯带本身仍整体显示同一种颜色。

新联动与按键输出共用后台调度和发送预算。键盘画面变化时，联动颜色接在完整按键帧后发送；静态键盘下，呼吸、采样和交融等仍可利用空闲预算继续变化，不必等 250ms 按键保活。

## 使用桌面版

适用平台：**Windows x64**。运行发布版不需要安装 Node.js、Chrome、Edge 或本地网页服务器。

1. 从仓库 Releases 下载 `HERO99HE-Light-Studio-0.2.2-win-x64.zip`。
2. 先从旧版系统托盘菜单中选择“退出程序”，并停止其他灯光软件的输出。
3. **完整解压 ZIP**，运行目录内的 `HERO99HE Light Studio.exe`。不要在 ZIP 内运行，也不要单独复制 EXE，旁边的 DLL 和 `resources` 必须保留。
4. 点击“连接键盘”，明确选择 HERO 99HE 的灯光接口。
5. 选择配色与键盘效果，点击“开始输出”。设置灯带模式后，点击“应用灯带”；单独应用灯带不必开启按键输出。
6. 关闭窗口会隐藏到托盘并继续运行。双击托盘图标打开面板，右键菜单可停止或彻底退出。

采用完整文件夹发布，解压一次后直接启动，不再每次启动都自解压整个 Electron 运行库。启动速度仍受磁盘和安全扫描影响。

程序没有发布者签名，Windows 可能显示未知发布者或 SmartScreen 提示。请核对来源和发布文件哈希，不建议关闭系统安全防护。

### 让灯带更亮

1. 将“灯带亮度”调至 **5 档**。
2. 将“鲜亮增强”从 **100%** 逐步调到 **150–200%**，再点击“应用灯带”。
3. 稀疏亮键、流星等场景可试“主色聚焦”，避免亮键被大量黑色背景平均压暗。

鲜亮增强会同比提高偏暗 RGB，并在最亮通道达到 255 时限制增益，避免各通道分别溢出改变色相；黑色仍为黑色。旧配置默认 100%，不会自动把已有场景调亮。

**它不能突破硬件亮度上限**：原生亮度仍为已实现的 0–4（界面 1–5 档），不会发送猜测的高档位或增压命令。如果 5 档、RGB 已满值的纯白仍明显低于官方驱动，请导出诊断并反馈模式、固件及对比条件；当前没有实机证据证明已达到官方驱动的同等最大亮度。

## 使用 Web 版

Windows 下双击 `HERO99HE-Light/启动控制台.cmd`，在 Chrome / Edge 打开本地地址：

```text
http://127.0.0.1:8731/
```

也可在仓库根目录启动服务：

```powershell
powershell -NoProfile -File .\HERO99HE-Light\Serve.ps1
```

只监听本机地址。默认端口为 8731，可通过 `-Port` 指定；不会修改原有 8720 服务。WebHID 需要受支持的浏览器和安全上下文，不建议直接双击 HTML。网页静态资源不依赖外站。

Web 版动态灯效需要页面和服务继续运行；希望关掉控制窗口后继续输出，请使用桌面托盘版。桌面版和浏览器配置分开存储，可以用导出/导入迁移；桌面版升级保持相同应用名及本地源，继续使用原桌面配置。

## 兼容范围与限制

- 当前接口检查：VID `372E` / PID `103E`，Usage Page `FF60` / Usage `61`，Report ID `9`，报告数据 63 字节。型号与报告描述必须同时符合；同名或其他布局不代表兼容。
- 支持范围限于现有 HERO 99HE 布局与已验证灯光通道；没有对全系列键盘或所有固件做保证。
- **Esc 实机灯光未响应的问题仍未解决**；预览位置和报文包含 Esc，不代表硬件已经点亮。
- 本版 PrtSc/Fn 修改的是显示标签与浏览器键码，保留原物理位置的硬件灯光地址，不重新猜测映射。Fn 通常不产生独立浏览器键盘事件。
- 按键互动只接收应用/网页有焦点时的事件，或手动点击预览键帽；**没有全局键盘钩子**，不能在游戏等其他窗口中监听按键。
- 动态灯效由本机实时计算，程序彻底退出、系统休眠或关机后不会继续生成；无设备离线动画保存功能。
- 没有开机自启、系统服务、自动重连或自动更新。每次启动仍需手动连接和开始。
- 灯带设置可能被设备记忆。停止或退出不保证恢复原厂灯效；需要恢复时使用官方驱动。不发送保存、恢复、重置或固件命令。
- 软件测试与模拟 HID 不等于实机 USB、视觉亮度或长时间稳定性验证。

## 流畅度与安全边界

复杂组合输出按需将相近颜色合并到最多 15 色、3 个键盘包，为灯带尾包留出带宽；仅按键输出仍为最多 24 色、4 包。低复杂度帧保持原色，原始色卡、涂色和动画配置不被改写。复杂联动会损失部分颜色层次，这是减少发送拥堵的取舍。

两路共用最多 80 包/秒的软件发送预算，包间隔至少 5ms，排空至少 8ms；串行发送，不追赶积压、不并发写入、不自动重试失败报告。灯带最快目标 40Hz，实际受包数、按键 FPS 和 USB 完成耗时影响，**不是所有模式都能达到 40FPS**。这些是软件策略，不是经厂商确认的固件规格。

桌面页面保留沙箱、上下文隔离和 Web 安全策略，不开放页面 Node.js；禁止远程导航、请求和弹窗。HID 只接受本地源、明确选择的合规设备。页面加载、连接、预览、导入和参数暂存不会自动启动灯光输出。

## 开发与打包

构建环境：Windows x64、Node.js **22.12+**、pnpm。固定依赖为 Electron **45.2.3** / electron-builder **26.18.0**；首次安装开发依赖和下载运行库需要网络。

在仓库根目录执行：

```powershell
cd HERO99HE-Desktop
pnpm install --frozen-lockfile
pnpm run prepare-web
pnpm start
```

构建完整应用文件夹：

```powershell
pnpm dist
```

结果为 `HERO99HE-Desktop/dist/win-unpacked/`。压缩**整个文件夹**再发布，不要只上传里面的 EXE，也不要把源码 ZIP 当作可运行发布版。
