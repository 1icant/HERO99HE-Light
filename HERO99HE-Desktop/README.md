# HERO 99HE Light Studio 桌面版 v0.3.3

Windows x64 便携版。内置 v0.1.26 网页，无需浏览器或本地服务器。键盘灯效从 32 种增加到 56 种，支持命名保存自定义配色。

1. 右键任务栏右下角的旧版托盘图标，选「退出程序」。点窗口右上角的 × 只会隐藏；旧版未退出时，打开新版会唤起旧窗口。
2. 将新版 ZIP 完整解压到新目录，再运行目录里的 `HERO99HE Light Studio.exe`。左上角应显示「桌面版 v0.3.3 · Web v0.1.26」。
3. 键盘、灯带、Logo 各自应用。灯带支持关闭、纯色、柔和呼吸、自动取色，以及原厂彩色霓虹、彩色跑马。自动取色在点击应用时取一次，不跟随键盘帧；呼吸和原厂彩色模式由固件播放。停止只停止软件输出，不关掉已应用的固件灯效。
4. 关窗收进托盘，软件灯效继续运行；双击托盘图标打开面板，右键可停止或退出。

Esc 专项与测试入口已移除，正常 101 键布局、灯效、色卡和时间线保留。旧灯带联动或已移除模式迁移为关闭，颜色和亮度保留；加载不会写硬件。Logo 保留原有独立模式。

「我的配色」可保存最多 60 组，包含主色、底色和整组渐变色，可随时套用或删除。配色库保存在当前应用的本地数据中，工作台 JSON 导出只包含当前项目。

「更多设置」可启用后台按键响应，仅在互动灯效需要时启动输入助手。Raw Input 是默认方案；兼容模式会响应所有键盘，须手动确认。不会记录按键明细。

## 资源占用

托盘隐藏和最小化时暂停预览，静态画面只在变化时刷新。静态按键保活复用已编码的帧；闲置 Logo 不轮询，灯带设置只在点击时提交。普通参数编辑和按键事件不会重复发送完整时间线。

## 构建

需要 Windows x64、Node.js 22.12+、pnpm 及系统 .NET Framework C# 编译器。安装开发依赖后运行 `pnpm start` 或 `pnpm dist`，两者会先同步相邻的 Web 源码。后者生成 `dist/win-unpacked/`，发布时完整压缩这个目录。已打包版本无发布者签名，核对值见 [SHA-256](EXE-SHA256.txt)。

软件回归见 [验证记录](TEST-RESULTS.md)。灯带呼吸按公开原厂模式编号实现，实物效果以实际固件为准。
