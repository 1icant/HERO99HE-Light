# HERO 99HE Light Studio 桌面版 v0.2.2

基于 v0.1.12 Web 页面，新增 6 种灯带联动、100–200% 鲜亮增强，并按新参考图调整 PrtSc/Fn 与 E 键间距。保留 v0.2.1 的流畅度优化。Windows x64 桌面程序，不需要另外打开 Chrome/Edge、Node.js 或本地网页服务器。不是狼蛛官方程序，未附带原厂驱动代码。

## 使用

1. 通过旧版系统托盘菜单“退出程序”，并停止、断开旧 Web 页面的输出。
2. 将 `HERO99HE-Light-Studio-0.2.2-win-x64.zip` 完整解压一次，进入文件夹双击 `HERO99HE Light Studio.exe`。不要在 ZIP 内运行，也不要只复制 EXE：旁边的 DLL、resources 等必须保留。免安装，无需管理员权限；不再每次启动自解压约 374MB 运行库。实际启动仍受磁盘和安全扫描影响。
3. 点击“连接键盘”，在程序自己的选择框确认 HERO 99 HE / HERO 99；连接本身不写灯。然后开始按键输出或应用灯带。
4. 点窗口右上角关闭，会隐藏到系统托盘，灯效继续运行；双击托盘图标重新打开。托盘图标可能收在任务栏的“^”里。
5. 右键托盘可停止灯效或彻底退出。退出会请求停止/排空，然后结束后台进程、释放 HID 句柄，不发保存、重置或恢复指令。

程序须在后台运行，不能做到彻底退出后仍计算动态灯效。Windows 睡眠、关机、任务管理器结束程序会中断；不主动阻止系统休眠。按键互动仍只接收程序窗口获得焦点时的事件，不是全局游戏按键监听。

## v0.2.2 联动与亮度

新增主色聚焦、横向追光、同色呼吸、互补映色、左右交融、击键闪耀；均是整条灯带颜色更新，不是逐灯寻址。旧配置鲜亮增强为 100%，需要提亮可选 5 档、150–200% 增强后点击应用。增益仅提高偏暗 RGB，保持色相、黑色与 255 上限；满值纯白无法继续提亮，未保证达到官方同等最大亮度。硬件档位不变，无新增未知协议。

完整 GitHub 首页说明见同级仓库根目录的 README.md；上传仓库时保留 HERO99HE-Light 与 HERO99HE-Desktop 两个目录。

## v0.2.1 卡顿优化（保留）

- 开启按键与灯带组合输出时，复杂按键画面最多 3 包、必要时合并到 15 色，为灯带尾包留出带宽。低复杂度原色不变；项目原始色卡、画笔和动画不被改写。仅按键输出仍最多 4 包/24 色。代价是复杂联动画面的颜色层次略减。
- “跟随”灯带复用同一个按键帧的未缩放原色，只在完整按键帧后更新，避免各自采样不同时间；独立灯带模式仍可利用空闲时隙。
- 预览最高 30FPS（或更低的所选 FPS），隐藏页面不重算预览；后台输出 Worker 不受影响。仍共用 80 包/秒预算、至少 5ms 包间隔、8ms 排空，不提高硬件写入速率。
- 同一真实 Electron 运行库、隐藏窗口、模拟 HID 的 3 秒对比：复杂联动由 47 帧变为 59 帧，平均帧间隔由 65.1ms 降到 51.7ms。不是实机性能保证；USB 完成耗时仍会影响效果。

## 配置与权限

- 32 种效果、30 组色卡、101 键布局、独立灯带亮度及发送预算原样保留。打开页面/连接/预览/导入不会自动开始输出。
- 应用名称和本地源未变，v0.2.0 桌面配置继续使用。桌面版配置和浏览器的 localStorage 分开。可在浏览器“导出”，到桌面程序“导入”。不会读取浏览器配置目录。
- 没有开机自启、系统服务、自动重连或后台升级。每次启动由你连接和开始；同一时间只运行一个桌面实例。
- 原生灯带可能被设备记忆，停止/退出不保证恢复原厂灯效；最高亮度仍限于原厂档位。不增加未知硬件指令。
- 此为本地自用、无发布者签名程序，Windows 可能显示未知发布者/SmartScreen 提示；不建议关闭系统安全防护。保留源码和 SHA-256 供核对。

## 封装与安全

使用固定版本 Electron 45.2.3 / electron-builder 26.18.0。所有页面资源打包进程序，不依赖 8731/8720 端口或外站，禁止远程导航与请求。页面禁用 Node.js、保持沙箱与上下文隔离；仅暴露托盘停止和运行状态的窄接口。

WebHID 只接受当前本地页面、显式选择的合规 HERO 接口；设备许可仅在进程内存保存。原有后台 Worker 继续持有 HID，不会因关闭窗口而销毁页面；禁用该窗口的后台节流。

## 从源码构建

需要 Windows x64、Node.js 22.12+ 和 npm/pnpm。先准备 `web/` 与图标：`node scripts/sync-web.cjs`（源网页默认取相邻的 `HERO99HE-Light`，也可传路径），再 `node scripts/create-icon.cjs`。安装开发依赖后运行 `pnpm start` 或 `pnpm dist`。`web/` 已附完整副本，已有副本时不必重新同步。

`pnpm dist` 生成 `dist/win-unpacked/` 文件夹，不再构建自解压 EXE。发布时压缩整个文件夹。

`node --test tests/*.test.cjs` 验证桌面壳策略与模拟生命周期；原网页测试另见相邻项目。软件测试不代替实机 USB/托盘长时验证。原项目、网页服务和历史压缩包保留。Esc 实机未响应的问题未在本次修复范围内。
